# Guia rápido para publicar seu portfólio

Arquivos criados:

- `index.html`: versão online pronta para GitHub Pages, Netlify ou Vercel.
- `portfolio-offline.html`: versão offline para abrir no navegador e salvar em PDF.
- `perfil-github-readme.md`: texto para usar no README do perfil do GitHub.

## Publicar no GitHub Pages

1. Crie um repositório chamado `portfolio` ou `henry842.github.io`.
2. Envie o arquivo `index.html` para esse repositório.
3. No GitHub, entre em `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/root`.
6. O link final ficará parecido com:
   `https://henry842.github.io/portfolio/`
   ou, se o repositório for `henry842.github.io`:
   `https://henry842.github.io/`

## Antes de enviar para carreira

- Troque `adicione-seu-email@example.com` pelo seu e-mail real no HTML.
- Se algum projeto ainda não tiver repositório público, deixe sem botão ou publique o código antes.
- Use o botão `Salvar em PDF` do portfólio para gerar a versão offline.
- No LinkedIn, coloque o link publicado na seção de destaque e no campo de site.
