# Henry Souza Santos | Portfolio Profissional

Portfolio online de Henry Souza Santos, com foco em Data Science, Machine Learning, Analytics, BI, dashboards e solucoes com IA.

Site publicado: [https://henry842.github.io/](https://henry842.github.io/)

## Objetivo

Este portfolio foi criado para apresentar, de forma clara e convincente para recrutadores, minha trajetoria pratica em dados. A proposta e mostrar nao apenas ferramentas, mas capacidade de transformar problemas em solucoes: entender o contexto, preparar dados, modelar, validar resultados e comunicar impacto.

## Principais Competencias

- Python para analise de dados, automacao e machine learning
- SQL para consultas, relatorios e analises de negocio
- Machine Learning supervisionado e nao supervisionado
- Dashboards e visualizacao de dados
- Feature engineering, validacao de modelos e interpretabilidade
- Aplicacoes analiticas com Streamlit, Flask, React e IA

## Projetos em Destaque

### InsightFlow AI

Plataforma de forecasting de vendas com upload de dados, KPIs, graficos, simulador de cenarios e exportacao de relatorios. E o projeto principal do portfolio por unir dados, modelo, interface e narrativa executiva.

### FinSight AI

Ferramenta de analise financeira com OCR e LLMs, voltada para health scores, sentimento, red flags e apoio a decisoes de investimento.

### Hypothyroid Pipeline

Pipeline de Machine Learning para previsao de hipotireoidismo, com pre-processamento, SMOTE, comparacao de modelos, analise de erros e interpretabilidade.

### DKidsFantasias Dashboard

Dashboard de vendas para analise comercial, acompanhamento de produtos, pagamentos e previsao de faturamento.

### Titanic CatBoost Pipeline

Pipeline para competicao Kaggle com CatBoost, K-Fold Target Encoding, feature engineering e cuidado contra vazamento de dados.

### VinEye

Projeto de Machine Learning para prever qualidade de vinhos a partir de variaveis quimicas, usando analise exploratoria, Random Forest e importancia de atributos.
